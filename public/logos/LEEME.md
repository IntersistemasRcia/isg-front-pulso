# ISG Pulso — icono propuesto

El símbolo representa una señal de pulso: lectura continua de la información del negocio. Utiliza únicamente azul `#545386`, naranja `#FF8300` y blanco `#FFFFFF` del manual de marca de interSistemas. No reproduce ni altera el logo corporativo.

## Archivos para uso

- `pulso-icon.svg`: fuente vectorial para pantallas internas.
- `favicon.ico`: navegador, con resoluciones 16, 32, 48 y 64 px.
- `pulso-16.png`, `pulso-32.png`, `pulso-48.png`, `pulso-64.png`: interfaces y pestañas.
- `pulso-180.png`: acceso directo Apple.
- `pulso-192.png`, `pulso-512.png`: PWA e instalaciones.
- `vista_previa.png`: revisión visual a distintos tamaños.

Es una propuesta nueva de ícono de producto. La aprobación final de identidad de ISG Pulso sigue pendiente en el AF.

## Referencias HTML

```html
<link rel="icon" href="/pulso-icon.svg" type="image/svg+xml">
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="apple-touch-icon" href="/pulso-180.png">
```

Para pantallas internas, usar el SVG con texto alternativo “ISG Pulso” cuando comunica la identidad del producto, o vacío cuando acompaña un rótulo visible.
